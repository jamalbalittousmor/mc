# The Backrooms

Браузерная игра на выживание в Закулисье: three.js + Rapier, один `index.html`, моды в `Mods/`.

**Играть:** https://jamalbalittousmor.github.io/mc/

- Исходники — в `src/` (`src/js/*.js` склеиваются по порядку имён). Собрать: `node tools/build.mjs`, авто-сборка: `node tools/watch.mjs`.
- Локальный запуск: `python -m http.server` в корне и открыть `http://localhost:8000`.
- Моддинг — см. [MODDING.md](MODDING.md), примеры — в `Mods/`.

## Версия 5.0
- Запечённый свет с тенями от мебели и стен, новые светильники, вода с отражениями, новые зоны (отель, школа, парковка, ТЦ, трубы, электрощитовая).
- Мебель, которую можно разобрать, руководства в журнале, главы заданий, новое меню паузы.
- Дополнение **Liminal Industry** (`Mods/li_*.js`): разборка, цех и электросети, гидропоника, аномалии и Резонансные врата — построенный выход наружу и «Новая игра+».

**Как играть без сервера:** распакуй архив и открой `index.html` (нужен интернет — библиотеки грузятся с CDN). Моды из `Mods/mods.js` подхватятся сами.

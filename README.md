# The Backrooms

Браузерная игра на выживание в Закулисье: three.js + Rapier, один `index.html`, моды в `Mods/`.

**Играть:** https://jamalbalittousmor.github.io/mc/

- Исходники — в `src/` (`src/js/*.js` склеиваются по порядку имён). Собрать: `node tools/build.mjs`, авто-сборка: `node tools/watch.mjs`.
- Локальный запуск: `python -m http.server` в корне и открыть `http://localhost:8000`.
- Моддинг — см. [MODDING.md](MODDING.md), примеры — в `Mods/`.
